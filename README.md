Netflix Clone 🎥🍿
A Netflix-inspired static web page designed using only HTML and CSS. This project focuses on replicating the UI/UX design of the Netflix homepage, showcasing responsive design principles and aesthetic layouts.

Features
Responsive Design: Adapts seamlessly to different screen sizes (desktop, tablet, and mobile).
Custom Styling: Styled using pure CSS for a clean and modern look.
Interactive Hover Effects: Enhances the user experience with smooth transitions and hover animations.
Netflix Theme: Accurate replication of Netflix's color scheme, typography, and layout.
